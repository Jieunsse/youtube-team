# 팀 IT 기술 유튜브 챌린지

수업에서 배운 IT 기술을 주제로, 한 사람이 쇼츠 영상 5개 이상을 만들어 각자 유튜브에 올립니다.
이 저장소에는 영상 제작에 필요한 도구, HyperFrames 스킬, 팀 공통 작업 수칙이 모두 들어 있습니다. 영상 파일은 올리지 않습니다.

## 미리 있어야 하는 것
- Claude Code (설치와 로그인까지 끝난 상태)
- Node.js 22 이상
- git

FFmpeg, Edge TTS, HyperFrames 스킬은 따로 설치하지 않아도 됩니다. 저장소 안에 들어 있습니다.

## 시작하기
1. 저장소를 내려받습니다.
   ```bash
   git clone <저장소 주소>
   ```
2. 내려받은 폴더를 Claude Code로 엽니다. 폴더를 신뢰하겠냐고 물으면 허용합니다.
3. 처음 열 때 필요한 프로그램이 자동으로 설치됩니다. 1~2분 정도 걸립니다.

처음 렌더링할 때도 영상을 찍는 데 쓰는 브라우저를 한 번 내려받느라 시간이 조금 더 걸립니다.

## 영상 하나 만드는 순서
1. [topics.md](topics.md)에 내 이름과 주제를 적어 선점합니다.
2. [PROMPT.md](PROMPT.md)의 요청문을 Claude Code에 붙여넣습니다.
3. 내용 구성과 대본을 확인하고 고칩니다.
4. 미리보기로 영상을 확인하고 고친 뒤, 렌더링해 달라고 합니다.
5. 영상 폴더의 `renders/`에 생긴 MP4를 유튜브에 올리고, [topics.md](topics.md)에 링크를 적습니다.

작업 수칙은 [AGENTS.md](AGENTS.md)에 있습니다. Claude Code가 자동으로 읽습니다.

참고로 7초짜리 샘플을 렌더링하는 데 1분 정도 걸렸습니다. 3분짜리 영상은 더 오래 걸리므로, 렌더링은 다 고친 뒤에 한 번만 합니다.
